# IoTConnect templates

This folder contains IoTConnect templates to simplify onboarding a RASynBoard device (V1.6.0+) and/or creating dashboards.

## RASyV1_6_template.json
This template describes the telemetry items that the Avnet Out of Box application supports as of the v1.6.0 release.  

To use the template create a new device template
- Open the templates screen
    - Devices-->Templates-->Create Template-->Import

## RASynBoard_generic_dashboard.json
This IoTConnect dashboard is architected to work with any  RASynBoard ML model.

To use the template you need to create a new IoTConnect Dashboard
- Create Dashboard-->Import Dashboard
- Select RASynBoard_generic_dashboard.json
